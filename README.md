# 🎓 EBAC — Módulo 15: Tailwind CSS

## 📖 Sobre

Projeto de estudo do Tailwind CSS (utility-first), com configuração de tema customizado:

```css
@import "tailwindcss";

@theme {
    --color-blue-500: oklch(0.6 0.1085 234);
}
```

## 🚀 Como rodar

```bash
npm install
# compile o CSS com o Tailwind CLI conforme configurado no projeto
```

## 🛠️ Tecnologias

HTML5 • Tailwind CSS v4

## 💡 O que aprendi

- Filosofia utility-first do Tailwind
- Customização de tema com `@theme` e cores em `oklch()`
